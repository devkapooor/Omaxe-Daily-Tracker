# Group Announcement - 11 October 2026

Send after deployment is confirmed:

**AlphaHub has been updated.**

- **Current Stock:** All staff can now view quantities, MRP, selling price, cost price and recorded stock movements, with search and filters.
- **POS Cart:** Product rows are now compact and consistent, making the cart easier to read.
- **GRN:** Added a receipt view showing previous recorded MRPs. Owners can Correct MRP or Reverse submitted GRNs. Quantity, cost price, MRP and selling price are mandatory. Selling price defaults to MRP and can be changed.
- **Owner Dashboard:** Today's POS sales are now shown in a single card.
- **Register:** Expense categories are now Rent, Electricity, Store Maintenance, Stock Delivery and Staff Welfare. Expense category names have been removed from the Party Directory view.
- **Loans:** All loan operations, totals and history are together on an owner-only page.
- **Cash Movement:** Cash transfers now check the sender's available balance before saving.
- Login error handling has been improved, and the unused Payroll page has been removed.

**Everyone must HARD REFRESH the app before using it: press Ctrl + Shift + R (or Ctrl + F5) while the AlphaHub page is open. A normal refresh is not enough.**

After refreshing, confirm that you can see **Current Stock** in the menu. Please report any issue in this group.
